# Saw & Gin English Lab v0.3

기존 v0.2 디자인을 유지하며 다음 기능을 추가한 정적 웹앱 초안이야.

- 홈에서 Vocabulary → Writing 순서
- 각 아카이브에서 최근 추가 / 먼저 추가 / EP 오름차순 / 내림차순 정렬 선택 저장
- 동사 MD에 `기본형`, `과거형`, `과거분사`가 있으면 세 칸 동시 채점
- 단어 시험 및 목록에서 수동 복습 체크, Review에서 재시험
- 홈에 XP, 레벨 게이지, 기본 업적 5개 표시
- 에피소드 파일은 자유롭게 추가하고 학습 잠금은 적용하지 않음
- 영작 첨삭은 기존처럼 Review에서 JSON 가져오기 → 에피소드 Writing Exercises에서 확인

`index.html`을 열어 시험할 수 있어. 샘플 MD는 실제 RP에서 인용한 것이 아닌 기능 테스트용 예문이야.

## v0.2 기록 이전

동일한 주소(동일 origin)에서 업데이트하면 이전 localStorage 키 `sawgin-lab-v01`을 그대로 사용하므로 기록을 읽을 수 있어. 다른 폴더의 `file://` URL이나 다른 도메인에서는 저장소가 분리될 수 있으므로, **v0.2 Settings에서 JSON 백업 후 v0.3 Settings에서 복원**하는 게 안전해.

## 제한

- 서버 동기화와 AI 자동 채점은 없음
- XP는 문제별 최초 성공/제출과 에피소드 최초 완료 상태를 기반으로 산정하며, 초기 데이터에는 일부 XP가 소급되지 않을 수 있음
- 동사 3단 변화는 세 칸 모두 정확해야 정답이며, MD에서 형태를 명시해야 함
- 복습 체크는 로컬 저장되며 단어 목록에서 언제든 변경 가능
- 배지와 레벨은 초기 게임화 시안이며 보상/난이도는 조정 가능
